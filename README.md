# PNS Wi-Fi & Outlet Map

給 Pensacola 在地人的極簡地圖：哪些咖啡店有 **Wi-Fi**、有 **插座**、適合帶筆電。資料由社群持續更新，每間店都標示最後確認日期。

> 網站內容為英文（給在地人使用）；本 README 與 `docs/` 文件為繁體中文。

- [計畫書 PLAN.md](docs/PLAN.md) — 目標、資料來源策略、技術架構、設計、路線圖
- [進度追蹤 PROGRESS.md](docs/PROGRESS.md) — 每個任務的狀態與驗證結果
